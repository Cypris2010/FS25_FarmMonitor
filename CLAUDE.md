# FarmMonitor — Claude Kontext

Dieses Projekt ist ein Farming Simulator 25 Mod (Lua). Der Mod heißt FarmMonitor und schreibt Spieldaten (Lagermengen, Preise, Felder) in eine JSON-Datei, die von externen Tools ausgelesen werden kann.
